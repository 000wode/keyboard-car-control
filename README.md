# 键盘遥控小车：USB 串口有线控制

本仓库提供 Arduino 固件和 Python 键盘监听上位机入口，通信方式统一称为 **USB 串口有线控制**。当前上位机不是 GUI 程序。

迁移说明：本仓库迁移自 `FireSafetyProject`，原提交历史见原仓库；迁移内容以本仓库当前文件为准。

> 实物接线经用户确认；当前硬件不在身边，未做通电复测。Arduino 控制引脚已与 `car_control.ino.ino` 中的 `IN1/IN2/IN3/IN4` 定义逐项核对，D4/D5/D6/D8 一致。

## 文件

- `car_control.ino.ino`：Arduino 固件，读取 USB 串口单字符并控制双 H 桥。
- `car_keyboard.py`：Python 键盘监听上位机，使用 `pynput` 捕获按键，使用 `pyserial` 发送指令；当前不是 GUI。
- `car_remote.ino.ino`：与 `car_control.ino.ino` 内容重复的保留文件；实际展示与复现入口以 `car_control.ino.ino` 为准。

## 接线说明（实物接线经用户确认；未通电复测）

| 连接端 A | 连接端 B | 说明 |
|---|---|---|
| Arduino Uno | 电脑 USB | 同时供电和串口通信 |
| Arduino D4 | L298N `IN1` | 对应固件 `IN1 = 4` |
| Arduino D5 | L298N `IN2` | 对应固件 `IN2 = 5` |
| Arduino D6 | L298N `IN3` | 对应固件 `IN3 = 6` |
| Arduino D8 | L298N `IN4` | 对应固件 `IN4 = 8` |
| Arduino GND | L298N GND | 共地 |
| L298N `ENA` | 跳线帽短接 | 全速运行，不使用 PWM 调速 |
| L298N `ENB` | 跳线帽短接 | 全速运行，不使用 PWM 调速 |
| 电池盒正极 | L298N `12V+` | 电机驱动电源输入 |
| 电池盒负极 | L298N `GND-` | 电机驱动电源地 |
| L298N `OUT1/OUT2` | 左马达 | 左侧电机输出 |
| L298N `OUT3/OUT4` | 右马达 | 右侧电机输出 |

接线核对结论：

- 用户提供的 Arduino 控制引脚 D4/D5/D6/D8 与代码完全一致。
- Arduino Uno 与 L298N 必须共地。
- 电池盒为 L298N 电机侧供电，不直接由 Arduino 板载稳压器为电机供电。
- ENA/ENB 使用跳线帽短接，当前固件只做方向控制，不输出 PWM。
- USB 串口使用 `9600 bps`。
- 上述接线来源为用户确认；当前硬件不在身边，未做通电复测，机械安装和实际动作仍需硬件可及时复核。

## Python 依赖

```powershell
python -m pip install pyserial pynput
```

`car_keyboard.py` 当前将串口写为 `COM3`。不同电脑需要先确认 Arduino 的实际端口，再修改这一行：

```python
ser = serial.Serial('COM3', 9600)
```

## 运行命令

1. 用 Arduino IDE 打开并上传 `car_control.ino.ino`。
2. 在电脑上确认 Arduino 串口编号，并保证 Python 脚本中的端口一致。
3. 运行：

```powershell
python car_keyboard.py
```

4. 按 `Esc` 退出控制端。

## 按键表

| 按键 | 动作 | 串口指令 |
|---|---|---|
| `W` | 前进 | `W` |
| `S` | 后退 | `S` |
| `A` | 左转 | `A` |
| `D` | 右转 | `D` |
| `X` | 停止 | `X` |

上位机对 `W/A/S/D` 松开事件补发 `X`，因此交互表现为“按下即走、松开即停”。`X` 也可直接作为急停键。

当前对外口径：代码支持五类动作并经现场联调，映射表与演示视频见本仓库；逐项复测记录待硬件可及后补。现有视频入口只用于核验公开演示，不能替代逐项动作复测或写成已经完成硬件复测。

## 常见问题

| 现象 | 优先检查 |
|---|---|
| Python 报串口不存在或拒绝访问 | 确认端口号、关闭 Arduino 串口监视器、检查 USB 连接。 |
| 小车不动 | 检查 L298N 供电、共地、D4/D5/D6/D8 接线和电机引线。 |
| 转向方向相反 | 硬件未复测，需在可接触实物时核对电机线序和左右轮定义。 |
| 松开按键后未停 | 检查 `pynput` 是否正常收到松开事件，并保留 `X` 键急停。 |
| 指令重复或抖动 | 当前脚本已做去重；仍需检查 USB 连接和串口缓冲区状态。 |
